# Ragupathi V — Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript.

## Preview locally
1. Download or clone this repository.
2. Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `ragupathi-portfolio`.
2. Upload `index.html`, `style.css`, `script.js` and this `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish the site. Your public URL will appear in the Pages section.

## Before publishing
- In `index.html`, replace `YOUR_EMAIL@example.com` with a professional contact email you are comfortable making public, or remove the email button.
- Add your GitHub profile and project repository links when you have them.
- Add screenshots, project demonstrations and verified technologies as your projects develop.
- Review all public contact and personal information before publishing. This template intentionally leaves out date of birth, phone number and street-level contact details.
